## Decision

- **A, usage preference: reject as tested.** It made no concept-conditioned gain and no gain in shared open-vocabulary headlines.
- **B, usage plus source order: revise; do not adopt.** It improved the concept test by 2.2 percentage points, but missed the pre-set five-point threshold and introduced a new homograph mismatch in the open sample.

## Open vocabulary and failures

All 207 development cases were evaluated. A changed two displays; B changed twelve. Every distinct new pair was reviewed with scores and variant names hidden, using all recorded sense context. Shared headline readings, including restricted overlap and documented name variants, remained **96/207** for the baseline, A, and B. This is not whole-word accuracy: a correctly contrasting false-friend pair need not share a meaning.

- B repaired the action/tool mismatch in English *scrape* and Swedish *skrapa*: it selected the Swedish scraping verb rather than the squeegee noun.
- B broke an existing English–Swedish *saga* narrative match by selecting the Swedish given-name reading. Ranking within each entry can favor the first sense of a separate homograph over a later appropriate sense in the main entry.
- A and B replaced a regional cooking-vessel reading of German *Pott* with bare “pot” against Swedish *pot, kitty*. The shorter wording still does not establish the intended shared sense; this remains unresolved, not a recovered match.
- Several changes merely chose a different nonmatching sense in genuinely disjoint pairs. Changing the diagnosis from “mismatch” to “no shared sense” is not an improvement.

B lost one shared headline in the names group (23 to 22 out of 50), the borrowing group (34 to 33 out of 60), and the different-root-language group (18 to 17 out of 26). These overlapping losses are the same saga case, not three independent errors. No group with at least 20 cases crossed the five-point loss threshold. All changed cases in smaller groups were read. Full counts and case IDs are in [open metrics](e1-run003/open_metrics.json).

## What this teaches us

A weak order preference helps some ordinary meanings, but dictionary order cannot decide which homograph or part of speech should stand for the pair. Usage tags alone affect very few cases and cannot repair unmarked secondary meanings. Many incorrect displays remain because a close-cosine window excludes a suitable sense or because different readings have similar glosses. These are observed limits, not permission to increase weights until this sample passes.

E2 should assess ordinary meaning coverage and grammatical compatibility across recorded senses, separately from history. Keep the unchanged baseline selector in both E2 arms so that a new label model cannot claim B’s display gains. Any stronger selector requires a new saved plan and separate run; no per-word exceptions were added.

## Control validity and secondary matches

- All 1,201 selected original rows were checked against the frozen Parquet. Definitions, complete sense lists, source identities and claims, maximum semantic scores, historical categories, relations, and translation references are unchanged.
- The reconstructed control matches every saved display. The largest cosine reconstruction difference is 0.000000477; no difference exceeds 0.001.
- All 81,143 pairwise cells are retained, including secondary and inactive context. Chosen display indices are separate from original match flags. No original sense or supported secondary correspondence was deleted.
- Only development families were opened. The 104 concept family groups, 2,000 paired bootstrap resamples, and seed 20261003 match the frozen procedure.

## Failed runs preserved

1. **E1-001:** translation eligibility ignored saved ambiguous-source candidate identities. Thirty-two reconstructed displays differed. No linguistic decision uses this run.
2. **E1-002:** translation reconstruction was corrected, but the runner chose the first normalized matching row instead of E0’s recorded row. Forty-four control-side displays differed and the baseline count became 633 instead of 630. The summarizer rejected it.
3. **E1-003:** eligibility honors ambiguous candidates and each selected row must reproduce the frozen E0 display. This is the valid comparison.

The row mismatch exposes an E0 limitation: case-folded identities can collapse distinct German capitalizations. E1 holds the recorded rows fixed and does not count changing the underlying headword as a gain. Future identity changes need their own before/after evaluation.

Selection parameters: close-score margin 0.10; order penalty weight 0.05. Model: the existing pinned multilingual MiniLM. Encoder, candidates, maximum scores, and ancestry classification stayed fixed.

The output directory must be new. Replay the saved judgments by identical concept/language/word/gloss identities, never by review number alone. The review commands use `--run` to select that directory. Existing result files are not overwritten.
