# E0 run 001: baseline coverage and saved review cases

Date: 2026-10-03. Status: running; E0 is not complete.

## What ran

The frozen five-language file was checked against its recorded SHA-256, then evaluated against all 1,712 between-language form comparisons in the selected modern IE-CoR varieties. Expected words, concepts, and expert cognate sets came from the published reference before reading pipeline predictions. Both directions count as one comparison.

The audit also saved a seeded sample of five rows per language-pair/category, with inclusion probabilities and separate blinded evidence and prediction files. Independent subtitle token-frequency samples were frozen before checking dictionary coverage.

No database writes or dataset changes occurred.

These are exact-spelling reference comparisons, after Unicode and case normalization. Inflected reference forms and spelling variants can count as absent exact headwords even when the dictionary contains a usable lemma. That is a mapping issue to investigate, not automatic proof of missing vocabulary. The report is a census of this reference panel, not a vocabulary-wide recall estimate.

Interpretation: many concept-equivalent, expert-related pairs are placed in lookalike or divergent-meaning categories. A concept-level cognate annotation does not establish that the entire words have identical usage. We must inspect the selected senses and historical evidence before measuring label errors. The reference may also overlap with claims used by the existing pipeline; ancestry scoring must record that overlap rather than call reused evidence an independent held-out result.

## Decision so far

**Coverage gaps are established on an independently selected basic-concept panel.** Candidate-generation testing in E4 is warranted. Dictionary coverage is strong for the most frequent subtitle tokens, but weaker in later bands, especially Danish and the generic Norwegian diagnostic. Neither finding establishes classification accuracy.

**No methodological change is adopted.** E0 remains running. The next work is to:

1. Map absent reference forms through recorded inflections and source identity; distinguish resolvable form differences from missing entries.
2. Review displayed meanings against the published concept guidelines, including ordinary versus secondary matches. Save the judgment, source basis, and unresolved status for each reviewed case.
3. Review the blinded open-vocabulary packet and add the planned hard-case groups. Report agent-assisted judgments separately from published expert annotations.
4. Assign family groups, keep inspected development cases out of the untouched test set, calculate grouped uncertainty for sampled quality measures, and freeze numerical acceptance limits before E1-E4 variants.

## Reproduction and evidence

Run from the repository root using the project virtual environment:

```powershell
.\pipeline\.venv\Scripts\python.exe pipeline/evaluation/e0.py prepare
.\pipeline\.venv\Scripts\python.exe pipeline/evaluation/e0.py audit
.\pipeline\.venv\Scripts\python.exe pipeline/evaluation/e0_frequency.py
.\pipeline\.venv\Scripts\python.exe pipeline/evaluation/e0.py verify
```

Commands refuse to overwrite completed artifacts. For another run, pass the same new `--output` directory to each command, for example `--output pipeline/evaluation/runs/e0-002`. Preserve the earlier results. Downloaded full references remain under ignored `pipeline/data/references`; protocol files record their content hashes and exact source URLs.

Saved alongside this report: concept cases and results, baseline metrics, blind review packet and separate predictions, frequency cases and results, source manifests and sampling protocols.
